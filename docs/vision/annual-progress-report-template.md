## Redaction / Privacy Checklist

Before publishing this report externally, verify each item:

- [ ] No specific customer names without written consent
- [ ] No revenue figures beyond what has been publicly disclosed
- [ ] No employee names beyond publicly listed team members (unless individual consent given)
- [ ] No partner names for partnerships not yet publicly announced
- [ ] No source-specific vulnerability information (e.g., gaps in coverage that adversaries could exploit)
- [ ] No internal system architecture details (infra, IP ranges, auth methods)
- [ ] AI model capabilities: describe capabilities, not weights or architectures
- [ ] User behaviour data: aggregate only, no individual-level data
- [ ] Legal review completed for any claims about accuracy, completeness, or methodology
- [ ] Translated version reviewed by native speaker before publication
