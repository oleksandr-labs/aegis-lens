## Quality gates (apply to every template)
- [ ] Minimum unique content threshold per page (or `noindex`)
- [ ] Per-template schema.org markup
- [ ] Internal links to ≥5 related pages
- [ ] Dynamic OG image
- [ ] hreflang for every supported locale
- [ ] Crawl-budget monitoring (Search Console + log analysis)

### Примітки
Owned by SEO + product. Threshold-gate every template before mass-publish.
